# R10 深入内容与正确性审计事务记录（2026-10-21）

## 目标、范围和原始状态
用户要求先完成内容充分性和正确性审计，再进入PPT。冻结研究问题：手机整体SoC2007–2026历史/机制/厂商多路线/归因，2027–2028条件性前瞻。审计前：v1.0技术报告，103条证据台账，历史偏旗舰/缺2007–2010同期原文，缺大众市场扩散样本。不是要扩大无关话题。

## 事实核查和修正
- 核2017华为Kirin970与Mate10同期官方页面、2007/2009 Qualcomm Snapdragon/工艺、2012 MediaTek MT6589、2013 Snapdragon410和2015商用节点。
- 保留2012 S4 LTE集成 vs 2019 865+X55平台配套/2022 Exynos2200集成的物理边界；M7为手机级协处理器，Google Tensor security core和Titan M2分开。
- 高风险2025–2026官方核对：MediaTek 9500 dynamic CPU/GPU/NPU data cache，Apple A20Pro的CPU Neural Accelerators/Dual 16-core NE/封装散热，Arm CSS Mobile2 C2/SME2/GPU神经加速，Qualcomm Hexagon Element Accelerator/+50% NPU shared memory为厂商设计披露。
- 独立研究依然按X01/X02同团队去重，X05排除手机Modem推导，X04/X10非电池功率，X07/X08同机构不同手机结果非裸片因果。
- Qualcomm S4白皮书PDF截图接口本次缓存异常，不将其物理块图视觉重核声称已完成。

## 真正发现的问题
1. 严重（AU-01）：旧103条CSV作者/年份/定位仅10条有值；对应判断、比较基线、单位等全部为空；它只是部分资料索引，不能称全量证据链通过。
2. 中高（AU-02/AU-03）：历史主体偏旗舰，需同年代起点与非旗舰；补七条A01–A07原始来源，强调发布→产品化→出货为不同事件。
3. 中高：未有受控任务/功率/温度A/B，无法分解工艺/软件与微架构因果，不凭空填性能百分比。
4. 报告仍缺103条老资料全文逐条核实、早期其他厂商覆盖和芯片内部NoC/各域功率数据。
