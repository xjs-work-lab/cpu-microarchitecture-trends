# 第十八轮研究事务：研究目标校正与 CPU 历史因果框架（2026-10-23）

## 1. 目标校正的触发

用户明确指出：本研究不是为了确定新的技术方向或提出新的立项建议，而是想理解移动终端 SoC，特别是 CPU，多年来发生了哪些变化；每项变化由什么原因导致、带来了什么后果；并以历史规律为未来提供参考。

此前第十六、十七轮部分措辞把 CPU 支线过度引向“技术决策”“可立项方向”和 Agentic/LLVM 未来优化杠杆。本轮纠正这一偏差。今后不把寻找新硬件方向作为研究主目标。

## 2. 研究目标（当前权威口径）

- **主问题：** 复盘 2007–2026 年智能手机 SoC 的历史演进，CPU 是重点深化对象；解释架构/微架构变化点、变化动因、收益、代价、瓶颈转移以及对后续演进的影响。
- **前瞻：** 基于历史因果链，对 2027–2028 年可能延续的趋势作有条件推断，写明证据、替代解释与不确定性；不强制输出新技术立项清单。
- **系统背景：** CPU 研究不能脱离 GPU、DSP/NPU、缓存/DRAM、OS 调度、编译器、制程、封装、功耗与热管理。
- **编译器的角色：** LLVM/ABI/SME 等资料用于解释软件如何利用、限制或放大硬件变化，不将编译器优化孤立成另一个立项目标。
- **证据纪律：** 区分原始资料明确陈述的设计动因、可由多个来源支持的分析推论、同期相关但未证实因果的现象，以及公开资料无法识别的部分。

## 3. 统一变化点分析模板

每个历史变化按以下字段研究：
1. 时间、产品/核心/ISA/系统层级；
2. 变化前的结构或主流做法；
3. 同期工作负载与技术约束；
4. 发生了什么变化（直接来源）；
5. 来源明确陈述的设计动因；
6. 收益或预期收益；
7. 代价、权衡、新瓶颈或职责转移；
8. 后续产品/软件/系统如何响应；
9. 证据类型和强度（FACT / CLAIM / OBSERVATION / INFERENCE / UNKNOWN）；
10. 竞争解释、混杂因素与不能下的结论；
11. 对未来趋势的有限启示。

## 5. 下一步

进入实际历史梳理，不继续泛化 seed discovery：
1. 先搭建 2007–2026 年移动 CPU 变化时间线的骨架；
2. 从代表性转折点入手：移动端性能/能效核心演进、big.LITTLE/异构多核与调度、64 位迁移、乱序与核心宽度/缓存等公开变化、SIMD/向量能力、DVFS/热限制，以及 CPU 与 GPU/NPU 分工的变化；
3. 每项变化追查当时官方设计说明、架构/核心白皮书、原始论文、产品资料与独立测量；
4. 用统一模板写出“背景约束—变化—收益—代价—后续影响”，把证据和推论分开；
5. 时间线与因果链基本成形后，再讨论 2027–2028 趋势，不预先假定趋势结论。
