# 第二十轮研究事务：跨厂商 CPU 路线与产品化时间（2026-10-23）

## 本轮问题
在第十九轮历史时间线基础上，核对不同厂商的 CPU 微架构路线、关键转向和产品化日期；区分核内微架构、半定制 IP、Arm Cortex IP 与 SoC 集成层设计。

4. 校正 Qualcomm 路线：Krait → 首代全定制 Kryo → Kryo 280 半定制 Cortex → Oryon；指出 Kryo 名称本身不足以判断微架构类型。
5. 加入 Samsung Mongoose/M1–M5 及 2019 年终止自研核路线；使用 Exynos 官方资料、ISCA 工业论文和 Yonhap 报道。
6. 区分 HiSilicon Kirin 980 的 Cortex-A76/A55 与 Kirin 9000S/9010 的 Taishan 第三方识别线索；后者的完整核内结构仍未知。
7. 核对 MediaTek Dimensity 9300、9500 与 9600 Pro 的 CPU IP/核心组合及产品日期；将 C1/SME2 的实际手机落地写入证据链。
8. 归纳自研核、半定制核、标准 Cortex 核、Arm CSS 平台四类路线；不以“自研”标签直接推定性能/能效更优。

## 阶段性结论
- 移动 CPU 历史不是所有厂商都不断增加核内自研投入的单一路径；厂商会在自研、半定制与标准 IP 之间切换，也可能终止自研项目。
- SoC 厂商即使采用 Arm 核，仍能在核心组合、频率档位、缓存/内存、调度、互连与异构计算协同方面进行设计。
- 产品公告时间与商业终端时间必须分开；产品化速度是观察项，不等于因果证据或性能优势。
- Kirin 9000S/9010 的 Taishan 核应作为第三方识别、非官方完整披露的证据类别单独管理。

## 本轮限制
- 本轮为公开来源审计，不包含统一设备测试。
- 厂商的性能/能效百分比不构成跨厂商可比排名。
- 对 Taishan 核的具体前端、分支预测、ROB/LSQ、寄存器文件和缓存结构仍缺少足够公开资料。
- 对 Samsung M5/M6 的 ISCA 论文分析，必须区分硅片实测与周期精确模型。
- C1/C2 设备的持续热性能、实际 SME2 软件覆盖和 agentic 任务能耗尚未独立验证。
