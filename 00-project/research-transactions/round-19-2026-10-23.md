# 第十九轮研究事务：移动 CPU 历史时间线与因果分析初稿（2026-10-23）

## 本轮目标

将第十八轮校正后的研究目标落到实际工作：开始建立 2007–2026 年移动 CPU 微架构历史变化时间线，重点解释变化点、同期负载与约束、设计者公开说明的动因、收益、代价、瓶颈转移及后续影响。不以发现新技术立项方向为目标。

## 本轮完成

1. 新建 [移动 CPU 微架构历史变化时间线 v0.1](../../03-analysis/移动CPU微架构历史变化时间线-v0.1-2026-10-23.md)。
2. 新建 [第十九轮初始来源审计](../../02-evidence/audits/round-19-cpu-history-timeline-source-audit-2026-10-23.md)，初步映射 18 组官方/技术来源及其证据边界。
3. 将历史演进分成早期乱序与多核、big.LITTLE、64 位迁移、持续性能/热效率、DynamIQ、Cortex-A76 与 X/A 核分层、Armv9/64 位大核、All-Big-Core、Qualcomm Oryon、CPU 侧 SME2 与 C2/持续 AI 工作流等节点。
4. 为每个节点初步标记因果证据强度，并将厂商声明与独立事实分开；未将厂商性能百分比当作统一独立测试。
5. 保留隐藏微架构的未知边界：没有从跑分推断 ROB/LSQ 容量、物理寄存器数、预测器结构或缓存命中率。

## 阶段性观察（非最终结论）

- 移动 CPU 的演进并非单一的“更高频率/更多核心”，而是逐步联合设计 IPC、异构核心、性能/能效分层、缓存/集群、软件兼容性和持续热表现。
- big.LITTLE/DynamIQ 与 All-Big-Core 不是简单的新旧替代关系；它们是针对不同产品目标的不同配置选择。
- ISA/向量/矩阵扩展必须经过编译器、ABI、运行时与应用采用，才能转化为用户可见收益。
- 2025–2026 年 CPU 侧 SME2 与 AI 工作流协调是最新公开设计信号，但尚不能推断所有手机会采用同一实现或相同软件路径。

## 本轮限制

- 时间线为初稿，尚未完成每个节点的产品上市/量产时间、同期竞争产品、原始文档版本和独立测量的逐项核验。
- 许多动因来自厂商自己的设计叙述；这些叙述证明厂商公开表达的设计目标，不自动证明全部因果。
- 跨代性能/能效百分比通常受制程、频率、缓存、内存、软件和整机散热共同影响。
- 当前来源重点偏向 Arm 与若干代表性厂商，尚需补齐 Qualcomm Krait/Kryo/Oryon 的历史连续性、Apple 自研核的代际证据，以及可公开核验的移动核内部微架构变化。

## 下一步

1. 按时间节点核对“发布—IP 可用—SoC 集成—终端上市”的日期，避免把宣布时间当作量产时间。
2. 深化 2007–2024 年可公开确认的核内微架构变化，优先核对取指/译码、乱序执行、分支预测、load/store、寄存器重命名与缓存层次。
3. 对 Qualcomm、Apple、Arm IP、MediaTek/HiSilicon 等路线建立并列比较，重点比较各自的设计取舍，不做没有统一条件的厂商排名。
4. 在关键节点上分别标出直接动因、合理推论、相关但未证因果和未知；必要时调整时间线表述。
5. 历史链条收敛后，再基于已观察到的长期变化讨论 2027–2028 趋势参考。
