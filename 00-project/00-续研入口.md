# 续研入口｜智能手机全 SoC 架构演进

**更新：2026-10-23（目标澄清后）。模式：PUBLIC_ONLY。GitHub main为跨聊天/Work统一研究状态。核心工作是历史变化与因果解释，不是新技术立项筛选；PPT批量制作仍暂停。**

## 核心研究目标
解释2007—2026智能手机整体SoC与终端平台随负载、能耗、安全和软件限制如何演进CPU、GPU、NPU/DSP、ISP/媒体/显示、通信/RF、缓存/互连、低功耗与热预算，并对2027—2028给出有证据和替代路线的条件性方向。见[五个最终研究问题](01-任务简报.md)。

## 当前状态
- **目标澄清（2026-10-23）：** 研究是复盘移动终端 SoC、尤其 CPU 多年来的变化点，解释每项变化的原因、收益、代价、瓶颈转移和对后续演进的影响；在此基础上为未来提供参考。不以提出新技术方向或立项清单为目标。详见[任务简报](01-任务简报.md)与[第十八轮目标校正记录](research-transactions/round-18-2026-10-23.md)。
- **下一步主线：** 建立 2007–2026 CPU 微架构历史变化时间线，按“变化点—背景约束/负载—架构变化—直接证据—收益—代价/新瓶颈—后续影响—证据强度”逐项核验。LLVM/ABI 用于解释软硬件关系，不是单独的立项目标。
