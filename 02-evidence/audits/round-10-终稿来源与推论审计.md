# 第十轮：技术洞察终稿的来源与推论审计

对象：[技术洞察终稿 v1.0](../../05-deliverables/05-智能手机SoC整体架构演进-技术洞察终稿-v1.md)；日期：2026-10-20。

## 1. 结构审计

| 审计项 | 检查结果 | 后续要求 |
|---|---|---|
| 研究范围 | 手机整体SoC/终端平台；2007–2026历史与2027–2028前瞻 | 不退回只谈CPU/GPU/NPU |
| 最终问题 | Q1–Q5逐项回答 | 技术专家审阅时确认每项可追溯 |
| 负载覆盖 | 视频、端侧AI、蜂窝通信、持续游戏四类 | 不能将单任务机制推广全部任务 |
| 物理边界 | 裸片、配套芯片、平台、整机/终端分层 | 特别注意M7、X55、RF/天线、封装/均热 |
| 证据等级 | FACT/CLAIM/OBSERVATION/INFERENCE/HYPOTHESIS/UNKNOWN | 不把结构发布或厂商主张写成独立测量 |
| 测量规范 | 单位、负载、版本、设备、功耗边界、时长和热条件 | 无可比基线不做性能排名 |
| 前瞻 | 方向置信度与收益幅度置信度分开 | 不预测未发布产品具体配置 |

## 2. 高风险主张的审计锚点

- **LTE 集成收益：** E02/P01/P02。28nm 与 CDRX 同期变化，不能单独归因基带集成。
- **手机级协处理器边界：** P03。M7 属手机系统级协处理器，不能画进A7裸片。
- **5G平台物理边界：** E05/P06/P07/N04–N06。865+X55是平台组合；集成/配套方案并存。
- **共享缓存/片内数据：** E08/E09/V06/V13/V14。存在结构信号，但缺逐任务缓存命中率、DRAM流量与功耗A/B。
- **AI实际执行路径：** V11/V12/M03。API能力、厂商峰值TOPS不证明指定模型实际使用哪个引擎。
- **无线定量：** X01/X02同团队；X04测TRP/TIS；X10测上行占空比；X05实际Laptop+CPE。各指标不可混成手机电池功率。
- **持续游戏：** X07/X08为同SoC不同终端且同一评测媒体，稳定性百分比不等于绝对FPS或能效；原因尚未拆分。
- **2026前瞻信号：** E10/E11/V13/V14分别属于IP发布、产品/终端披露或厂商技术主张，不代表全市场量产采用及独立收益。

## 3. 明确接受的公开限制

当前公开资料不能普遍获得：各产品NoC物理拓扑、每个电源域瞬时功率、跨引擎实际数据流/缓存命中率、同工艺同软件跨厂商受控A/B、未来产品真实采用率。报告将其标记为UNKNOWN，不将“未公开”写成“没有”。

## 4. 审计范围声明

此审计检查终稿的核心结构和高风险推论锚点，**不等于对103条台账来源逐条重新核验，也不等于实验复现或法务/安全审查**。后续技术专家若指出具体主张，按证据ID定向回查原始来源并更新版本。
