## 二、项目现有洞察（需带证据边界使用）

手机SoC演进可用五阶段解释：**早期连接与媒体集成→异构CPU、ISP/DSP与低功耗常驻→专用神经处理和5G平台→跨引擎任务协同→数据/软件与终端电热治理**。八个旗舰/核心代表平台之外，现增加2007–2009早期Snapdragon、2012 MT6589、2013/2015 Snapdragon410与2017 Kirin970→Mate10发布链，以减少旗舰与年代偏置。

四条系统工作负载（4K视频、端侧AI、蜂窝通信、持续游戏）有不同的QoS和瓶颈。跨引擎缓存/局部性值得研究，但不能说它是所有任务的普遍首要瓶颈；5G网络条件/射频、游戏帧时序与整机热、AI软件/模型支持均不可忽略。**严禁用厂商TOPS、3DMark稳定性%、无线TRP dB、论文摘要的某个百分比直接承诺裸片微架构收益。**

2027—2028仅推断多域AI、数据/存储QoS、无线低功耗、影像/AI协同和持续电热等**条件性方向**，同时保留替代路线、证伪条件和公开资料限制。
